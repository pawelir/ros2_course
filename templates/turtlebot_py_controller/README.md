# turtlebot_py_controller (template)

Starting skeleton for the course exercises. Copy it into your workspace `src/` in module 2:

```bash
cp -r /workspaces/ros2_course/templates/turtlebot_py_controller /workspaces/ros2_course/src/
```

Then build with `colcon build --symlink-install` and source `install/setup.bash`.
